# Pocket Ledger

Pocket Ledger is a simple, polished budget tracker mockup built to practice front-end design and data presentation. The page presents a clean monthly budget overview with income, expenses, and spending categories, giving the project a realistic dashboard feel.

## What I built

- A responsive budget dashboard layout
- A spending breakdown with category labels
- Summary cards for income, total expenses, essentials, and non-essentials
- A clear remaining-balance view with status messaging
- Share-ready metadata and a custom favicon for a professional public preview

## Current status

This version focuses on the visual design and front-end presentation. The JavaScript functionality for interactive calculations and dynamic budgeting will begin next week.

## Live demo

The project is published through GitHub Pages and can be shared publicly once the repository is connected to the Pages site.
